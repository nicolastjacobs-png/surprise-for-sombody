# A Surprise for Willow

A private interactive romantic surprise experience made for Willow.

## How to use

1. Download or open `index.html` from this repository.
2. Open it in any modern browser.
3. Enter the password when asked (ask Nicolas if you don't have it).

## Features

- Password-protected entry
- Three discovery presents with hidden messages and clue numbers
- Progress saved in the browser
- Soft ambient audio + sound effects (with mute)
- Beautiful proposal sequence that unlocks on the special date
- Mobile-friendly with reduced-motion support

## Notes

- Best experienced with sound on
- Progress persists via localStorage
- The final present unlocks on **31 December 2026 at 12:00 UK time**
- To reset progress, open the page with `#reset` at the end of the URL
